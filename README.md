# debian-openbox
Projetos de instalações debian minimalistas com uso do openbox

Após a instalação do sistema base com o debian netinst ou ubuntu-minimal, abra o terminal e proceda:

sudo apt install git

git clone https://github.com/koiollevado/debian-openbox

Logo após baixá-los, entre na pasta debian-12 e, dê permissão de execução ao arquivo install.sh

chmod +x install.sh

Daí, basta seguir a ordem dos scripts para instalação e configuração.
